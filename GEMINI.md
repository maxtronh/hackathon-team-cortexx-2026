## Code Standards
- Use descriptive variable/function names in English.
- All components must be self-contained with clear props.

- Never commit `node_modules/`, `dist/`, `.env`, or API keys.

## Git Workflow
- Branch naming: `feature/<short-desc>`, `fix/<short-desc>`
- Commit messages: conventional commits (`feat:`, `fix:`, `chore:`, `docs:`)
- Always pull before pushing. Resolve conflicts locally.
